Política de Privacidad

Cómo este sitio estático gestiona información y servicios de terceros.

Información recopilada

Esta versión de Manu es un sitio estático y no recopila intencionadamente nombres, correos electrónicos, credenciales ni formularios.

Alojamiento y datos técnicos

El sitio está alojado mediante GitHub Pages. El proveedor puede procesar datos técnicos de solicitud, como dirección IP, navegador y registros, según sus propias políticas.

Enlaces de terceros

Las páginas pueden enlazar a servicios externos como GitHub y ThreeUI, que tienen sus propias prácticas de privacidad.

Cambios futuros

Si se añaden analítica, formularios, cookies, publicidad o cuentas, esta política deberá actualizarse antes de activarlos.
